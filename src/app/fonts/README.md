# Local font sources

These files are self-hosted to keep production builds independent of the Google Fonts network endpoint while preserving the existing families and weight ranges.

- `Geist-Variable.ttf`: Geist variable upright, weight 100–900, from the authoritative [Google Fonts Geist directory](https://github.com/google/fonts/tree/main/ofl/geist).
- `PlayfairDisplay-Variable.ttf`: Playfair Display variable upright, weight 400–900, from the authoritative [Google Fonts Playfair Display directory](https://github.com/google/fonts/tree/main/ofl/playfairdisplay).

Both fonts are licensed under SIL Open Font License 1.1. Their unmodified license texts are included alongside the corresponding font file as `Geist-OFL.txt` and `PlayfairDisplay-OFL.txt`.
